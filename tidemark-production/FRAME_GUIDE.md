# Tidemark card frame guide

Reference image: [`reference/card-frame-guide-v1.png`](reference/card-frame-guide-v1.png) (the owner's proposed visual guide, 2026-10-18).

**Status:** accepted as the **visual reference** for the card frame: the look, colours, layout and rarity emblems. The rules text, names and symbols in the mockup are placeholders that drifted toward Magic: The Gathering; the corrections below (agreed by the owner, 2026-10-18) override the image wherever they differ. The game draws every frame in code; SOL never paints frames.

## What to keep from the image

- A clean, timeless frame that puts the illustration first; the same layout for every card type.
- Name bar at the top with the cost circle on the right.
- A **4:3 landscape art window**, the same shape as SOL's sheet cells.
- Type line with the faction icon at its right end.
- A light parchment rules box (rules text, then italic flavour text).
- **One emblem at the bottom centre** shows the set and the rarity by its finish: Common black, Uncommon silver, Rare gold, Legendary prismatic. The frame itself does not change with rarity.
- Power/Toughness box at the bottom right, **Units only**.
- Collector line at the bottom left.
- The faction colours of the banners (blue, green, red, teal, purple, gold, brown).

## Corrections (they override the image)

1. **Cost shows Tidemark's resources, not mana.** The cost corner shows the **Influence** cost (a number) and the **Allegiance** requirement as pips: Land (stone), Sea (wave), or both for Dual; no pips for Neutral. A card marked *Land 2* shows the cost and two Land pips. No water-drop symbol.
2. **Rules text uses Tidemark's vocabulary**, generated from each card's effects (as Wildkin does), so text and play cannot disagree:
   - The only keywords are Charge, Surge, Rampart, Leader, Swift, Undertow, Tough, Trample and Ferry N. There is no Vigilance.
   - "Units", never "creatures"; "enters play" or "enters the Shore/the Deep", never "the battlefield"; "deck", never "library".
   - No card produces a resource with a tap symbol: Influence grows by itself each turn (Strongholds give defensive bonuses and screens).
   - The type line names the card type (Unit, Spell, Relic, Vessel, Stronghold, Domain, Enchantment) with a subtype. Land and Sea are **allegiances**, never card types ("Land / Stronghold" is wrong; "Stronghold" with Land pips is right).
3. **Neutral gets a colour and an icon:** stone grey with a **waystone** (a standing road stone). 24 anniversary cards are Neutral.
4. **Collector line:** set code and number, e.g. **TT 042/220** (Tenth Tide), never a faction code. Alternate art: **TT 221/220** to **TT 230/220**. Each set has its own emblem; Tenth Tide's emblem carries an **X** for the tenth year (the image's "IV" was a placeholder).
5. **Names come from the checklist** (`CHECKLIST.md`). The mockup's Harbor Sentry, Coastal Tactician and Azure Command are not cards; "Isolde, Dowager Queen" is **Dowager Queen Isolde**.
6. **Free Fleets icon: a ship's wheel** (the sun in the image is replaced). An anchor was the alternative; the wheel says sailing, while an anchor says harbour, which belongs to the Harbor Leagues.
