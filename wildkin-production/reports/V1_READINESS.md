# Wildkin Version 1: readiness assessment

Date: 2026-10-13. Manifest 1.0.0. Written by Claude Code after milestones A to D. Live art numbers: `outstanding_assets.md` (regenerated by `tools/wildkin_manifest.py`).

## Short answer

The game machinery for Version 1 is done and tested. First Bond (Set 001, 180 cards) has replaced the prototype set in the game. The art pipeline works. **Version 1 is not ready to ship** because of three gaps the code cannot close: art (5 of 180 cards are finished), card rules (all provisional), and owner confirmations (inferred families and provisional affinities).

## What was tested (and passed on 2026-10-13)

- `tools/wildkintest.py`: all 180 cards match the manifest by number, id and name; category and rarity counts; every one of 331 prints renders; no card shows art not mapped to it; placeholders wherever art is missing; premium cards have their own illustration IDs; identities identical across worlds; 40,000 packs all follow 6/2/1/1 with odds matching the manifest; buy, open a pack and a box, grade, list, buy from the market; five weeks of metagame with evolution lines in decks; save and continue; a real prototype-era save is labelled, not loaded, byte-for-byte untouched, and still exportable; the 3D viewer rasterises cards with linked art.
- `tools/wildkin_econ.py`, 12 months: pack value $5.1 to $5.9 (price $4.50), box $174 to $256 (price $150; sealed rises after the first year by design), Cactuft SIR about $410 to $480 raw and about $2,100 to $2,400 at GCS 10, 15 deck archetypes, top deck about 20%.
- `tools/test_art_pipeline.py`: see milestone D.
- `tools/shelltest.py` for sports, comics and tcg; `tools/playtest.py` for comics and tcg: clean.

## Not tested

- The GitHub Actions workflow has not run (it only triggers on files in `incoming/`). The commands it runs are the ones tested locally.
- A real SOL delivery. The intake was tested with stand-in sheets made from the owner's existing art.
- Real phones, itch.io, a GPU 3D viewer (unchanged from before).

## Blockers for shipping Version 1

1. **Art.** 161 cards wait for art. Every premium card (40), every ally, gear, tactic and biome illustration, and 69 creatures. Start with sheets 02-09 and 11 (canon mascot families). See `ART_QUEUE.md`.
2. **Designs.** Only five creatures and no human character have an approved look in this repository. SOL needs concepts approved first (process in `SOL_HANDOFF.md`, section 4). The owner has character reference images from earlier planning; they need to come into the repository.
3. **Owner confirmations** (`reconciliation.md`): the provisional affinities of 51 creatures, the order of 173-176, 177-180 and 075-092, mascot fandom ranking, the look of a Clasp, which stage the existing koi sheet is.
4. **Card rules.** Every attack, HP value, weakness and effect is a generic placeholder so the simulation runs, and cards say "Provisional rules". Real rules need a design pass. When they exist, they go into `manifest.json` and nothing else changes.
5. **Essence art.** No sheet in the plan. Essence cards are drawn as vector designs, which is acceptable for launch but should be decided.

## Known limits of the current game

- **One set only.** No Set 002 exists, so there is no rotation, no next-set preview and no preorders. The metagame settles (the same deck leads all year) and no ban triggered in a 12-month run. Long-term progression comes back when more sets are defined.
- **Prototype saves cannot be played.** Their cards were prototype creatures that are not canon. They are kept untouched, labelled in the launcher and can be backed up. A new First Bond game can run beside them.
- **Release date** of First Bond (6 February 2026 in the game calendar) and the code `FBD` are provisional.
