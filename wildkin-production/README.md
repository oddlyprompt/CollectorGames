# Wildkin production

The shared ground between Claude Code (cards, game, checks) and SOL (art). Start with `SOL_HANDOFF.md`.

| Path | Owner | What |
|---|---|---|
| `manifest.json` | Claude Code (generated by `tools/wildkin_manifest.py`) | The 180 First Bond cards, species, families, affinities, art IDs, each with a canon/inferred/provisional status |
| `art_queue.json`, `ART_QUEUE.md` | generated | Every sheet SOL must make, cell by cell, with production status |
| `reports/reconciliation.md` | generated | The 43-sheet plan against the cards: inferences, gaps, duplicates |
| `source/appendix_a_roster.tsv` | extracted from the bible | The 180 names, the only input for names and numbers |
| `incoming/` | SOL | Deliveries |
| `approved/` | `tools/wildkin_art.py` | Approved pieces (`assets/`), original sheets (`sources/`), `registry.json` (provenance), `superseded/` |
| `rejected/` | `tools/wildkin_art.py` | Refused deliveries with the reason |
| `reports/<TASK>/<hash>/` | `tools/wildkin_art.py` | Review page and contact sheet for each delivery |
