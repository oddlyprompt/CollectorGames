## QC / handoff

- 48 C + 36 UC + 30 R + 14 SR + 2 SEC = 130.
- 6 Rare variants + 8 SR variants + 2 SEC variants + 1 unnumbered hidden EB = 17. **Total: 147 illustrations.**
- EB and SEC must never feature the same character in a given set.
- Each card must match its episode and introduction chronology. Nexus is a voice only in Set 01; do not reveal full character.
- Characters have fixed body/face/outfit models; anatomically sound poses. Avoid text as part of generated art except deliberately controlled prop easter eggs; typeset copy in game.
- Meta jokes are character-specific and sparse; no gag required on most art.
- Claude Code defines gameplay and final card-type implementation, and validates all mechanical consistency.
